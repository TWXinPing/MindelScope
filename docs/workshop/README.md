# Open science workshop pack

Four pieces to walk out with: the problem, the language, a **static** evidence slide, the ask.

The MOSAIC interactive viewer is a separate sandbox and is **not** part of this pack until [sandbox/mosaic/STATUS.md](../../sandbox/mosaic/STATUS.md) is complete.

| File | Use |
|---|---|
| [pitch-outline.md](pitch-outline.md) | 8–10 minute talk |
| [visual-language-onepager.md](visual-language-onepager.md) | Handout / glyph sheet |
| [demo-script.md](demo-script.md) | What to show instead of the live viewer |
| [recruitment.md](recruitment.md) | Roles to fill |
| [feedback-form.md](feedback-form.md) | Capture glyph readability |
| [figures/](figures/) | Optional simulation diagnostics (not the visualisation product) |
