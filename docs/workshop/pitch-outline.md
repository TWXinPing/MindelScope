# Pitch outline (8–10 min)

## 1. Problem (2 min)

Show five failure modes of conventional cognitive-model figures:

1. **Unstable glyphs** — a rounded box means “process” in one paper and “memory” in the next.
2. **Ambiguous arrows** — the same line is a signal, a gate, and a learning rule.
3. **No time** — MOSAIC is a switching story told as a still.
4. **No way in** — nested modules without a zoom path.
5. **No situation** — the plant is an abstraction, so readers cannot map it onto reaching through water.

## 2. Claim (1 min)

We do not need another simulator warehouse. We need a **shared visual language** (MindelSpec) plus a viewer that can play traces and bind boxes to real events. Tools and a catalog come after the language exists.

## 3. Evidence (3–4 min)

Do **not** open the MOSAIC sandbox viewer. Follow [demo-script.md](demo-script.md): glyph sheet + (optional) static simulation plots. The interactive MOSAIC figure graduates into this slot later.

## 4. Ask (2 min)

Four roles, not “join us”. See [recruitment.md](recruitment.md). Hand out the glyph sheet and the feedback form. If there is a hackathon block, run the 90-minute task: draw the first five modules of a second model in v0 glyphs.
