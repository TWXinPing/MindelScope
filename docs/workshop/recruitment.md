# Who we are recruiting

Do not ask people to “help build a platform”. Ask them to take one of these jobs.

| Role | First deliverable after the workshop | Why it is real work |
|---|---|---|
| Cognitive / computational neuroscientist | A second classic model in MindelSpec v0 (Predictive Coding, DDM, or ACT-R productions) | Tests whether the glyph set generalises |
| Scientific visualisation / design | A printable glyph sheet and greyscale check | Colour-blind and photocopied papers must still parse |
| Open-source engineer | Schema tests + GitHub Pages deploy of the viewer | The demo has to survive without Colab |
| Teaching / science communication | One undergraduate lab sheet that uses a *situation script* (not the unfinished MOSAIC viewer) | Situation mapping is a first-class object |

## 90-minute hackathon task

In pairs, pick a model you already know. Using only v0 types, draw five modules and four edges on paper or in `/authoring/`. Fill goal / equation / scenario for each node. Grey anything you are not simulating. Present for 90 seconds.
