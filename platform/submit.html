Submit a model

What to upload

  1. A .mindel.json file that validates against MindelSpec.
  2. Optional traces.json bound to module ids.
  3. At least one scenario script that names a real behaviour.
  4. A citation and an interpretation status.

Classic-model confirmation

If you are visualising someone else’s published model:

  1. Start as unofficial interpretation.
  2. Contact the original team (or a named domain reviewer) with the viewer link and a one-page mapping of nodes to paper sections.
  3. Only after written confirmation may the badge become author-confirmed.
