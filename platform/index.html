MindelScope

A shared visual language for cognitive neuroscience models — time, probability, and real situations included.

Catalog Guidelines Submit a model Authoring tool

Not another model repository

ModelDB and Open Source Brain already store simulators. MindelScope stores a diagram with meaning: what each box does, which equation it implements, how signals evolve, and which everyday behaviour it is supposed to explain.

Visual language v0

Eight module types, four edge types, three annotations per node.

Author-confirmed path

Classic models stay unofficial until the original team (or a named reviewer) signs off on the meaning.
